## Scope

Protect the independent Feedback service deployment, configuration and
owned state in production. Ordinary Studio API use does not claim Studio's
runtime. Cross-service exact-revision acceptance acquires all required resources
in the order defined in the resource policy. Production still requires explicit
authorization. Resolve the deployed service identity before the first operation.

## Acceptance criteria

- [ ] Record target, revision, operation, backup and rollback plan before mutation.
- [ ] Preserve exclusive state ownership and verify the exact deployed revision.
- [ ] Record acceptance or safe rollback before release.

## Lifecycle

This resource is reusable: release it, never mark it done. Never automatically
release a stale ENV claim; verify a stopped holder and use fenced recovery.
